Langkah Pemesanan

Bagaimana Cara Order?

Proses pemesanan sangat mudah, cepat, dan dijamin aman. Ikuti panduan di bawah ini.

1

Pilih Layanan

Pilih jenis akun premium dan durasi yang Anda inginkan dari daftar pricelist.

2

Hitung dengan Kalkulator

Gunakan fitur kalkulator untuk generate format pemesanan instan.

3

Hubungi Admin WA / IG

Kirim format atau konsultasikan detail pesanan Anda pada Admin kami.

4

Pembayaran Aman

Lakukan pembayaran via Transfer Bank (BCA/Mandiri/BRI) atau E-Wallet (Dana/OVO/GoPay).

Akun Premium Dikirim

Setelah pembayaran diterima, akun premium pesanan Anda akan langsung diproses 1-15 menit!

Tips & Edukasi

Panduan Penggunaan Akun Premium

Dapatkan pengalaman terbaik serta pastikan masa pakai akun premium Anda maksimal dengan mengikuti panduan ringkas berikut.

Mencegah Screen Limit Netflix

Bagi pengguna paket Sharing, disarankan hanya login di 1 device saja. Hindari mengganti profile pengguna lain agar tidak terjadi tabrakan device.

Dilarang Mengubah Password

Mengubah password atau email akun tipe sharing sangat dilarang dan dapat menghanguskan status garansi aktif Anda secara permanen.

Cara Praktis Klaim Garansi

Apabila akun memerlukan verifikasi ulang, cukup screenshoot kendalanya lalu kirimkan langsung ke admin via WA/Instagram dengan menyebutkan ID Invoice.
